大肥鱼启动器 v0.3（DeepSeek Harness 桌面启动器 · 鲸鱼娘皮肤）
========================================

一、怎么用
1. 解压到任意固定文件夹（比如 D:\DSH）
2. 双击 DSH.exe 即可
3. 想要桌面快捷方式：右键 DSH.exe → 发送到 → 桌面快捷方式

二、它会自动做什么
- 自动找到你电脑上的 DeepSeek Harness 桌面版（标准安装位置）
- 没运行时自动帮你启动；已运行就直接显示运行状态
- 华丽二次元皮肤：深蓝渐变圆角窗、金色描边、蝴蝶结、星星、气泡、流动光效
- 左上角是完整的鲸鱼娘立绘，五个按钮各有自己的小头像
- 标题下方每次打开都会换一句「鲸鱼娘想对你说的话」（共 100 句，连着开也不会重样）

三、五个按钮都是开关 / 两段式
- 打开界面：DSH 窗口显示着 → 点它变成「关闭界面」（收进托盘，不结束进程）
            窗口收起来了   → 点它重新打开界面
- 检查插件：第一次点 = 查有没有插件能更新（会说「有 N 个可更新」）
            第二次点 = 真的去更新（更新完自动变回「检查插件」）
- 检查本体：只查 DSH 本体版本 + 可更新插件数，不装任何东西
- 启动语音：语音引擎（GSV，端口 9880）没跑 → 帮你拉起来（约 10~30 秒）
            已经在跑 → 点它变成「关闭语音」，再点一次就关掉
- 关闭：关掉这个启动器窗口（DSH 本体不受影响）

四、DSH 装在别的地方怎么办
编辑同目录的 launcher.ini，把 exe= 那行改成实际路径（去掉行首分号）：
  exe=D:\DeepSeek Harness\DeepSeek Harness.exe

五、注意
- 「检查插件」的更新动作需要电脑装了 Node.js（默认 C:\Program Files\nodejs\node.exe）
  且 DSH 里启用了插件市场；没装 Node 只是更新按钮用不了，其余功能不受影响
- 启动器本身不提权、不弹 UAC、不开机自启、不改注册表
- 语音引擎默认不再随 DSH 自动启动；想用语音时手动点「启动语音」
- 要彻底退出 DSH：用 DSH 托盘图标右键 → 退出
- 卸载：直接删掉这个文件夹（+ 桌面快捷方式）即可
- 窗口按 Esc 可直接关闭
